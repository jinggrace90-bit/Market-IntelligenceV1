# Freemasonry Site (static)

A simple static website scaffold about Freemasonry.

Quick preview:

```sh
# Serve the site locally from the freemasonry_site folder
python3 -m http.server --directory "freemasonry_site" 8000
# Then open http://localhost:8000 in your browser
```

Files created:
- `index.html` — homepage and meta description
- `about.html` — full introduction and interpretation
- `styles.css` — basic styles

Placeholders have been replaced with NewZealand Lodge (No. 123) and contact secretary@lodgename.com. Edit the HTML files to change these values.
